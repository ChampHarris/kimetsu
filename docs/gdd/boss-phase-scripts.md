Boss Phase Scripts
Every boss is a phase script on the shared Domain engine: phases advance at HP or Posture thresholds or at scripted events (a
place, a time, a decapitation), every attack uses one of the four telegraph answers, and the neck follows the Decapitation rules
unless a script says otherwise. This tab also sets the finale's Fate conditions.

 Rule                         Detail

 Scaling                      HP and Posture scale with the party, NPC companions counting as half; timings and telegraphs never do

 Phases                       Phases advance only on the way down from full health. Finale Upper Moons regenerate to full before their wing
                              opens

 Thread                       Opens per the Decapitation rules (a Posture break, 0 Hunger or collapse) unless a script says otherwise

 Second wind                  Among NPC bosses only Akaza and Kokushibo have one, as their scripts say, and Daki's first decapitation isn't one.
                              Player-held seats keep the general rule

 seats                        Downed before that Upper Moon falls

 Player-held Hashira seats    The retired canon Hashira still fights in their wing as a Cultivator, and the Fate is about them; the player Hashira
                              fights normally

 Nakime                       The castle's biwa player is always NPC Nakime, whoever holds Upper Four

 Later countdowns             The first finale settles the Fates; later ones play the current seat holders

 Echoes                       Replays run the same script with the Fate already settled
