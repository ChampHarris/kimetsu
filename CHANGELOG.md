# Changelog

## Unreleased: Build 0 (M1 grey box)
- The mod project exists (2026-10-19): `kimetsu` 0.0.1 on Minecraft 26.3 and NeoForge 26.3.0.92 from the official MDK, Gradle 9.2.1 with a checksum-pinned distribution and a Java 25 daemon, a `core/` subproject for the rules (compiled on its own and into the mod), and dev-only MCTest, spark, JEI and WorldEdit. No gameplay yet.
- Build 0 GameTests check that the vanilla-scope pack loads and applies: Champ's removals are tagged, and every recipe and advancement the pack overrides is gone from the running game.
- Fixed, both found by those GameTests: the Build 0 pack disabled the eye, rib, snout and spire trim recipes while vanilla's two trim advancements still named them, which stopped the world loading (now 773 files: those advancements go too); and NeoForge's own copies of 446 vanilla recipes shadowed 36 of the pack's disables, so the vanilla swords, bow, crossbow, shield, arrow and netherite ingot could still be crafted (the mod now loads after NeoForge).
- Nothing shipped yet. The Claude Code kit, Round 6 proposals and M1 starting numbers are in the repo.
- Round 7 (kit and data only, no mod code): the vanilla-scope datapack under `src/generated/scope/`, the Corps Record starter advancements, townsfolk name data, a 16 px sample block, and the tools that make and check them.
- The vanilla scope is staged by milestone. The Build 0 pack (771 files) disables 507 vanilla recipes and their recipe-book advancements, tags the removed items, potions and mobs, empties the ruined-portal and stronghold structure tags, rewrites the trade tags without the 20 trades that give or want removed items (an emptied level adds no offer), and strips removed items and potions from loot. Its spawn modifiers start mattering at M3: the biome modifier then removes the night hostiles from the overworld's spawn lists, the structure modifier the outposts' pillagers and the swamp huts' witches, and `remove_vanilla_features` the dungeons and infested stone. Vanilla advancements go at M2, the night hostiles, raids and armour at M3, structures and non-Japanese biomes at M5, in a new Taishō world (1,479 files, with the villager converting to a townsperson).
- Fixed before any code depended on them: the biome modifier's `entity_types` field, the strip modifier's potion field, the Corps advancements' load conditions and faction predicates, and stale pack files (the pack now deletes only what its manifest lists).
- Second review round: `vanilla_scope.py` reads the structure templates (jigsaw by jigsaw, processors applied), trades from their traders, loot weights, killer and biome conditions and the cobweb's correct tool. That found waxed copper bulbs and ancient cities' Nether blocks generating after their removal (they now stay until M5), the creeper's skeleton-only discs (now go at M3), trades selling the removed sword (now dropped), and that cobwebs need the blade to keep the sword's tool rules. Lock and pack now record content hashes of rules, data and tool; the Corps root's icon is the blade; "Flow" replaces "Total Concentration".
- Third review round: Bad Omen comes only from the ominous bottle, so ominous trials and raids are now gated on it; removing the bottle at Build 0 had orphaned the flow banner pattern, the Creator disc and the ominous trial key, so the bottle and those three go at M3 with the raiders. An axe scraping a trial chamber's waxed copper bulb made a removed block, so every copper bulb waits for M5. The tool now models what vanilla survival reaches by breeding, by code drops and by world rules (19 items it had missed, such as dead coral, turtle eggs and the trial chambers' sherds), either-or loot conditions, expanded tags, a pool's potion, villager types and trade components; it checks rule entries that can never apply, dead recipes and empty trade levels, and reports what an older world would carry into a later milestone. The lodestone stays (its recipe is stone bricks and iron); projectiles go at M3 with the mobs that shoot them; the Java list adds `LivingConversionEvent`, server-side `EntityJoinLevelEvent` for every join, and potion contents in `LivingDropsEvent`.
- Fourth review round: an emptied villager trade level now stays empty, because taking the level below would repeat offers the villager already holds (certainly for four of the five levels, about 1 in 8 for the mason's); `"empty_trade_levels": "lower"` restores the fallback if 26.3 mishandles an empty set. `--stages` now counts what an old world can hold from the milestone being played, placed blocks included (175 removed blocks at M5, not 81). Turtle eggs and the other blocks mobs lay count as found, not placed. `--check` also fails on a trial spawner config that names no mob, and a rule entry check that missed globs now covers them. The scope pack moved to `src/generated/scope/`, because datagen deletes whatever its providers didn't write in `src/generated/resources/`. The ocelot note no longer credits NeoForge with skipping it: the data alone keeps it out of the hostiles tag. The freshness hashes now read CRLF as LF and the tools write LF, so a Windows checkout of the same rules and data doesn't look stale. Every tool prints UTF-8 and the settings set `PYTHONUTF8=1`, so townsfolk names no longer crash a Windows pipe.
