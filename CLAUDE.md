# Kimetsu: Breath & Blood

Champ's lore-accurate, skill-first Demon Slayer (Kimetsu no Yaiba) action RPG for Minecraft Java 26.x on NeoForge, for Slayers and demons, multiplayer-ready with a full single-player game. It's a private build for Champ's own play and is never published, so there are no publishing, licensing or AI-disclosure rules (D-010). The quality rules stay.

**Roles.** Champ owns taste, scope and approvals. You are the lead designer-engineer: you research first, push back with evidence, propose the better version, and prove your work. The output style "Kimetsu Lead" spells out how.

## Non-negotiables
1. **Research before proposing.** Check the GDD and its Merge Log first; never resurrect a cut idea without a new argument. Tag evidence `[canon]` `[prior-art]` `[tech]`.
2. **Judge every idea on merit,** Champ's, yours and other games'. Novelty earns nothing by itself: a proven mechanic that passes the adopt check (`docs/taste.md`) is adopted, credited and improved for this mod. Before agreeing to an implementation, name at least two flaws in it first: budget, desync, Mixin risk, a missing API (D-018). Keep the best, remove redundancy, extend an existing system before adding one.
3. **Don't invent design silently.** A missing number, rule or name gets a PROPOSED value and a question for Champ. Raise design problems; don't patch them in code.
4. **Verify every API in `ref-src/`.** 26.x is newer than most training data.
5. **Server-authoritative, need-to-know networking, frame data is the source of truth** for hits and cues; animations follow it.
6. **Menial vanilla stays; the rest is the mod's own and blends with it.** Ores, coal, torches, stone, crafting, farming and building blocks keep vanilla's art (`art/vanilla-scope.json`). Everything else a player meets is the mod's own, at vanilla's 16 px and on vanilla-like ramps, so it sits beside vanilla stone, dirt and foliage without a seam (R7-01, R7-02). AI may make any of it. Claude doesn't rip or recreate official art, music or voices, and doesn't draw canon characters' likenesses; those come from Champ.
7. **Only Champ approves specs.** The hooks enforce this.
8. **Evidence before "done":** the command you ran and what it printed (build, test counts, a Lens contact sheet or MCTest screenshot you looked at).

## Commands
```bash
./gradlew build                       # compile, test, jar
./gradlew :core:test                  # fast rules tests (no Minecraft)
./gradlew runGameTestServer           # in-world tests; exit code = failed required tests
./gradlew runClient                   # dev client (Lens scenarios run here; MCTest drives it)
python tools/check_spec.py docs/design/specs/*.md
python tools/palette_fit.py draft.png out.png --palette art/palettes/world/sugi.gpl   # 16 px, one ramp, blend check
python tools/vanilla_style.py --all   # the blend check: every mod texture against vanilla's style
python tools/make_ramp.py             # rebuild the Taisho material ramps (art/palettes/world/)
python tools/texture_lint.py          # art bible on every PNG
python tools/vanilla_scope.py --stages # what goes at each milestone, what breaks, which mod sources are needed
python tools/vanilla_scope.py --check  # every milestone to the target: unclassified, orphans, worldgen leaks, stale pack
python tools/vanilla_coverage.py --top 40   # restyle backlog
python tools/audio_lint.py --loudness
python tools/townsfolk_names.py --town 40 --region tohoku   # sample a town; --check tests 2,000
python tools/sims/duel_sim.py         # M1 fight Monte Carlo (v0 numbers in tools/sims/m1_v0.json)
python tools/sims/pulse_sim.py        # Pulse and deflect timing model
python tools/sims/night_sim.py --nights 300   # night Director: demons per party size (the R7-03 table)
python tools/refsrc.py                # Minecraft + NeoForge sources into ref-src/ (--assets, --data, --mcmeta 26.3)
```
On Windows use `gradlew.bat` in cmd or PowerShell, or `./gradlew` in Git Bash; use `py -3` if `python` isn't on PATH.

## Architecture
- `core/`: plain Java 25, no Minecraft imports (hook-enforced): meters, the Pulse clock, frame data, the combat state machine, hit resolution, the strike scheduler and judge. JUnit only.
- Mod module: NeoForge glue. Data Attachments (per-entity state, synced on change), SavedData (world state), datapack registries (forms, frame data, arcs, combat rules, later arts, missions, boss phases), `CustomPacketPayload` + `StreamCodec` payloads, events.
- `client.render` / `kfx`: all drawing, on RenderPipelines, submitted render features and post-effect JSON. No raw OpenGL (hook-enforced). Works on Vulkan with no shaderpack first.
- `src/generated/scope/`: the vanilla-scope datapack for the current milestone. Generated; never edit it by hand. It has its own folder because datagen's `runData` deletes whatever its providers didn't write in `src/generated/resources/`. Change `art/vanilla-scope.json` and rerun the tool; when a milestone starts, bump its `milestone` first.
- Rules per area load automatically from `.claude/rules/` (Java, rendering, content data, assets, design docs).

## How we work
- **Design:** `/forge <topic>` (or the `/design-forge` workflow for big, contested questions) → a spec in REVIEW → Champ approves → build. `/scout` researches, `/redteam` attacks, `/numbers` simulates.
- **Build:** plan mode for anything touching more than three files. `/verify-api` before unfamiliar APIs. `/goal` for long tasks with a checkable end state (tests green, check_spec passing). IntelliJ's MCP server gives diagnostics, builds and the debugger (ADR 0002).
- **Visuals:** `/lens <scenario>` and read the sheet; MCTest for screenshots and tick stepping in the running game; `/ref-clip` for timing references; `/texture-pass` for art batches.
- **Writing:** the `dialogue-writer` agent writes townsfolk line banks and barks.
- **Versions:** `/port-plan <version>` before any Minecraft or NeoForge hop. **Milestone gate:** `/milestone-check` (Champ triggers it).
- **End of session:** `/session-close` updates `docs/state.md`, `docs/decisions.md` and `docs/gotchas.md`.
- Build order (GDD): M1 combat core → M2 cold open and Slayer slice → M3 demon core → M4 Domain engine and first bosses → M5 living world → M6 paths and endgame powers → M7 story and factions. Don't pull later features forward.
