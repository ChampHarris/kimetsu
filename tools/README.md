# Tools

Python 3.10+ (stdlib) plus Pillow for image tools (`pip install pillow`) and ffmpeg/ffprobe for audio and video tools. Every tool prints a readable report, supports `--help`, and exits non-zero when it finds errors, so hooks and CI can use it.

| Tool | What it does | Typical command |
|---|---|---|
| `check_spec.py` | Validates design specs against the template (sections, research tags, options, PROPOSED numbers, tests, sources) | `python tools/check_spec.py docs/design/specs/*.md` |
| `vanilla_scope.py` | Applies `art/vanilla-scope.json` (keep, restyle, replace, remove, each from a milestone) to the real 26.3 data. An obtainability fixpoint over recipes, loot (weights, rolls, expanded tags, either-or, tool, killer and biome conditions), worldgen (biome features, surface rules, and structures followed jigsaw by jigsaw through their templates), spawns and breeding, trades (each from its trader and villager type), world rules (an axe, weathering, coral dying), raids and ominous trials (Bad Omen), and interactions finds the kept items the removals orphan, the ones left thin, and the removed blocks the world still generates or makes, at every milestone; then it writes the current milestone's datapack (trade tags without removed trades, spawn modifiers for biomes and structures) and the lock, both stamped with content hashes of the rules, the data and the tool. `--stages` shows each milestone, judges each mod source and says what an older world would carry into it; `--why <id>` traces one item, block or mob; `--check` gates CI (also on dead recipes, a profession's first trade level left empty, trial spawner names it can't map to a mob, and rule entries that can never apply) | `python tools/vanilla_scope.py --stages` · `--milestone M5 --orphans` · `--datapack src/generated/scope --lock` |
| `vanilla_coverage.py` | Restyle coverage from the scope lock: which restyled vanilla textures still lack an override; `--strict` fails on gaps | `python tools/vanilla_coverage.py --top 40` |
| `palette_fit.py` | Turns a draft into a lint-clean 16 px texture: grid, one material ramp, clean alpha, a tiling check, the blend check and a 3×3 preview; `--log` records the recipe and `--method` in `art/art-log.csv` | `python tools/palette_fit.py draft.png <target>.png --palette art/palettes/world/sugi.gpl` |
| `vanilla_style.py` | The blend check: measures a texture against vanilla's style for its family (`art/vanilla-style-stats.json`, numbers only); `--preview` tiles it beside vanilla neighbours (needs `refsrc.py --assets`) | `python tools/vanilla_style.py --all` |
| `make_ramp.py` | Builds vanilla-like material ramps (hue held, chroma rising toward the highlights) from `art/palettes/world/ramps.json`, plus their union `taisho-world.gpl` | `python tools/make_ramp.py` · `--show sugi` |
| `make_test_floor.py` | Writes `kimetsu:test_floor`, the empty 16×4×16 structure the combat GameTests stand on, so the runner waits until every chunk a fight uses ticks entities (D-087), and `kimetsu:test_cells`, the same at 51×4×21 for `ten_fights_in_budget`'s ten walled cells (D-094); `--size 1 1 1 --out empty.nbt` writes the same NBT as vanilla's `empty.nbt` (only the gzip header differs); `--check` compares the NBT of both | `python tools/make_test_floor.py` · `--check` |
| `texture_lint.py` | Art bible on every PNG: names, 16 px blocks and items, atlas sizes, animated strips, cutout alpha, emissive layers, palettes, reserved cue colours | `python tools/texture_lint.py` |
| `townsfolk_names.py` | Generates a sample town from `data/kimetsu/townsfolk/names.json` (the executable reference for the Java generator); `--check` generates 2,000 towns and fails on a canon name or a broken repetition cap | `python tools/townsfolk_names.py --town 40 --region tohoku` |
| `audio_lint.py` | OGG Vorbis, mono for positional sounds, sample rate, streaming, sounds.json references, loudness and true peak | `python tools/audio_lint.py --loudness` |
| `side_lint.py` | Client-only code stays in `client` packages: a Java file elsewhere that names `net.minecraft.client`, `com.mojang.blaze3d`, `com.mojang.renderpearl` or NeoForge's client packages (in code, not comments or strings) would crash a dedicated server when its class loads. The post-edit hook runs it on each edited Java file; `side-lint: allow <reason>` on a line exempts it | `python tools/side_lint.py` · `python tools/side_lint.py <file>` |
| `contact_sheet.py` | Labelled contact sheets from Lens captures, MCTest screenshots or frame folders, with `--crop` | `python tools/contact_sheet.py run/lens/<id> --cols 8` |
| `clip_to_frames.py` | Reference video → frames, hold/key detection, contact sheets, a PROPOSED frame-data beat sheet (local only) | `python tools/clip_to_frames.py clip.mp4 --name slash_ref` |
| `refsrc.py` | Extracts Minecraft + NeoForge sources (and optionally vanilla assets, data and library sources) into `ref-src/`. `--mcmeta 26.3` fetches the vanilla data alone from misode/mcmeta, with no Java, and resumes; it also fetches the overworld structure templates (NBT) and summarises them in `structure_palettes.json` for `vanilla_scope.py` | `python tools/refsrc.py --assets --libs` · `--mcmeta 26.3` |
| `sims/pulse_sim.py` | Perfect Deflect odds, on-beat duty cycle, masher Rhythm gain | `python tools/sims/pulse_sim.py --rtt 100` |
| `sims/duel_sim.py` | Monte Carlo of the M1 fight with the v0 numbers (`sims/m1_v0.json`) | `python tools/sims/duel_sim.py --set m1_demon.hp=120` |
| `sims/night_sim.py` | The R7-03 Night Director: kills, time engaged, hits taken and demons alive for 1 to 6 players; `--set 'director.waves="fixed"'` is the starved baseline | `python tools/sims/night_sim.py --nights 300 --moon quarter` |
| `fight_report.py` | What the fight logs (`run/kimetsu/fights/*.jsonl`, D-069) say, per session: fights and time to kill against the sims, the guard from the engine's own deflect record (`GuardJudged`: verdicts, timing error and calibration, every guard inside its window that failed and the gate it failed), dodges, clashes, splats and mashing, holds, movement clamps, the link (`gapMax`, `silence`, RTT, decision delay), the budget's step figures, and the cheat flags (Perfect share, clash reaction runs; thresholds from the options); `--player`, `--json`; exits 1 on a malformed line | `python tools/fight_report.py run/kimetsu/fights/*.jsonl` · `--json` |
| `tests/test_vanilla_scope.py` | Unit tests for `vanilla_scope.py` on synthetic data | `python tools/tests/test_vanilla_scope.py` |
| `tests/test_fight_report.py` | Unit tests for `fight_report.py` on synthetic lines, and a smoke run on trimmed real logs (`tests/data/fight_sample.jsonl`) | `python tools/tests/test_fight_report.py` |

Planned (listed in `.claude/hooks/validators.json`, written once the M1 spec fixes the schemas): `validate_frame_data.py`, `validate_arcs.py`.
